# i3

Everything needed (i3, rofi, kitty, xss-lock, polybar...) is installed by `nixos/configuration.nix`, and this folder is linked as `~/.config/i3` by `install.sh`.

| File | Content |
| --- | --- |
| `config` | the i3 config |
| `workspaces.conf` | the workspaces of each screen |
| `screens.conf` | generated by `screen_management.py` (not versioned) : the screens of the current autorandr profile, then includes `workspaces.conf` |
| `screen_management.py` | applies the autorandr profile and writes `screens.conf` (at login, `$mod+Shift+c`/`r` and after each screen switch) |
| `screen.json` | for each autorandr profile, the main screen (`screen1`) and the others, by EDID |
| `rearrange_workspaces.py` | moves the open workspaces back to their screen (after a screen switch, or `$mod+Alt+r`) |
| `autorandr/` | the autorandr profiles and the `postswitch` hook |

> Warn : to use kitty with ssh, type `kitten` before. Like : `kitten ssh truc@truc.fr`

## Multiscreen

[here](https://fedoramagazine.org/using-i3-with-multiple-monitors/) to read. Use [autorandr](https://github.com/phillipberndt/autorandr) to handle multiple screen configuration.

The autorandr profiles are in `autorandr/`, linked as `~/.config/autorandr/` by `install.sh` (with the `postswitch` hook updating i3 and polybar after each switch). To add a new setup :
- place the screens with `xrandr`, then `autorandr --save <profile>` (`--force` to update an existing one) : it is written directly in the repo
- add the profile in `screen.json` (the EDIDs are in the `setup` file of the profile) : `screen1` is the main screen, `screen2` and `screen3` the others (`null` if missing)

An unknown screen (a video projector...) isn't turned on by autorandr (no matching profile) and gets no workspace : all the workspaces stay assigned to the main screen. Once turned on (`xrandr --output <port> --auto --right-of eDP-1`), i3 only shows an empty workspace on it, move one there by hand with `$mod+Alt+4`.

# Power button

To capture the power buton, check `/etc/systemd/logind.conf`. For nixos [here](https://nixos.wiki/wiki/Logind). (that disable the default behavior, then use i3 to capture it)
